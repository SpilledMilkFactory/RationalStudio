Step 1 — Configure
From your Rational Studio repository root, execute:
cmake -S . -B build-issue60-windows `
    -G "Visual Studio 17 2022" `
    -A x64 `
    -DCMAKE_PREFIX_PATH="C:/Qt/6.10.2/msvc2022_64" `
    -DRATIONALSTUDIO_BOOST_INCLUDE_DIR="C:/dev/vcpkg/installed/x64-windows/include" `
    -DRATIONALSTUDIO_BUILD_GUI=ON `
    -DRATIONALSTUDIO_BUILD_CLI=ON `
    -DBUILD_TESTING=ON `
    -DRATIONALSTUDIO_BUILD_BENCHMARKS=OFF `
    -DRATIONALSTUDIO_BUILD_ADVANCED_GRAPH_BENCHMARKS=OFF `
    -DRATIONALSTUDIO_ENABLE_LINUX_PACKAGING=OFF

Note: These are PowerShell commands. The backtick character at the end of each line is PowerShell's line-continuation character. It must be the final character on that line.

If everything is configured properly, CMake should identify:
- MSVC as the C++ compiler.
- Qt6 Core, GUI, and Widgets.
- Boost.Multiprecision headers.
- The Windows x64 platform.
- Rational Studio's registered test targets.
The final lines should resemble:
-- Configuring done
-- Generating done
-- Build files have been written to: ...

If CMake reports that Qt or Boost cannot be found, stop there rather than changing source files speculatively.
7. Build the Windows Release Configuration
Now we can build Rational Studio.

Run:
cmake --build build-issue60-windows `
    --config Release `
    --parallel 4

That's our first native Windows compilation.

This is the point where MSVC may identify cross-platform issues that GCC didn't reveal.

For example, differences in compiler diagnostics, floating-point behavior, or Windows-specific type handling might surface.

Our goal is to resolve any genuine compatibility problems while preserving the mathematical behavior we've already qualified on Linux.

If compilation succeeds, we should have:
build-issue60-windows\
    Release\
        RationalStudio.exe
        RationalCLI.exe

The exact output location is controlled by the CMake target configuration, but this is the conventional Visual Studio generator layout.
8. Run the Automated Windows Tests
Before testing the graphical application, we should run the automated regression suite.

Because Windows doesn't necessarily know where Qt's runtime DLLs are installed, we can temporarily make them available to this PowerShell session.

Execute:
$env:PATH = "C:\Qt\6.10.2\msvc2022_64\bin;" + $env:PATH

Now configure Qt's offscreen platform for automated testing:
$env:QT_QPA_PLATFORM = "offscreen"

First, inspect the registered tests:
ctest --test-dir build-issue60-windows `
    -C Release `
    -N

Our current Linux GUI baseline contains 73 CTests.

Ideally, the Windows configuration will register the same test inventory. If any tests are conditionally excluded on Windows, we should inspect the reasons rather than automatically assuming that's acceptable.
Run the complete Release regression
ctest --test-dir build-issue60-windows `
    -C Release `
    --output-on-failure `
    --parallel 4

Our acceptance target is:
100% tests passed, 0 tests failed out of 73

That is the target, not a result we've verified yet.
Build and test Debug
One advantage of the Visual Studio generator is that we don't need a separate CMake configuration directory for Debug.

Run:
cmake --build build-issue60-windows `
    --config Debug `
    --parallel 4

Then:
ctest --test-dir build-issue60-windows `
    -C Debug `
    --output-on-failure `
    --parallel 4

Again, we're targeting all 73 registered GUI and mathematical tests.

If both configurations pass, that will establish a meaningful native Windows regression baseline.
9. Launch Rational Studio Normally
After the automated tests pass, remove the offscreen setting:
Remove-Item Env:QT_QPA_PLATFORM -ErrorAction SilentlyContinue

Ensure Qt's DLL directory is still in your current session's PATH.

Then launch:
.\build-issue60-windows\Release\RationalStudio.exe

The normal desktop GUI should appear.

I recommend manually checking the four workspaces we developed during previous milestones:
Workspace	Suggested verification
Scientific	2+3*4, sqrt(81), RAD/DEG
Graphing	y=sin(x), y=x^2, inequalities, zoom
Exact Fractions	1/2 + 1/3 = 5/6
Advanced Math	Complex arithmetic, differentiation, matrices


Also verify that the application settings persist, graph workspaces save and reopen, keyboard shortcuts work, and resizing doesn't make controls inaccessible.

This will complement the automated smoke tests from Issue #63.
